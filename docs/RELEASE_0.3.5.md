# 0.3.5-trophy-fix

2026-11-08。以冻结的0.3.4-story-compat为基础，仅修正通关标识查询。

用户反馈：0.3.4中的海盗／风来人通关标识仍缺失，其他问题已解决。

原因已定位：0.3.4把读取后的英文职业记录转换到了局部字符串cself[8]，但真正决定奖杯图标的45个条件分支仍查询全局字符串S0。显示名称已是中文，S0中的旧记录仍用英文，因此匹配失败。旧测试只验证了局部替换结果，没有覆盖后续实际查询变量，未能发现这处遗漏。

本版将三个奖杯函数（741、806、846）的45个条件、共72个变量操作数，改为查询已经转换的cself[8]。包含普通通关、不同难度、无仓库和狂热模式的图标判断；条件文本、图标编号和通关规则不变。只改公共事件资源中的变量操作数字节，资源长度不变。S0与存档不会因此被改写。

新增回归测试读取真实公共事件条件及原有25条职业映射，复现“局部已转换但旧条件仍失败”，然后检查海盗／风来人的3,456组条件操作数用例，包括四个难度、不同通关目标、附加模式模板、中文记录与未知职业的反例。另检查所有其余事件字节保持一致，尤其死亡原因显示路径。离线检查不能代替游戏内验收。

其余201项资源与0.3.4逐字节一致：全部译文、序章／结尾正文、旧死因兼容、字体、187张文字图、菜单动作及19项属性译名均继承。不增加翻译条目。

具体变更证据见trophy-query-diff.json；测试与独立EXE隔离安装／还原证据见test-verification-0.3.5.json、release-verification.json及isolated-install-audit.json。

升级：退出游戏，完整解压本版玩家ZIP，运行新版安装器，先“还原原版”，再“安装汉化”。保留.mcowh-zh-backup和存档；无需重新通关。开发方不启动或操作游戏，通关标识由用户在选职业界面复验。
