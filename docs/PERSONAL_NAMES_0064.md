# 人名暂留英文（0064）

用户最新要求：“对于人名相关的翻译，我都希望可以先保留英文形式”。已设为全局临时规则，覆盖此前确认过的中文人名，适用于后续新增人物。

本轮修订389条已有译文，没有新增翻译条目。范围包括姓名标签、对白、人物名衍生的装备／技能／地点名称，以及具名妖精、神明、动物同伴和联动角色。普通称谓、职业和非人名专有名词继续中文。例如：Keyton之剑、Dosey的Sp.疗伤草、Konrath国王、Konrath城堡；艾尔扎特炸弹、纳尤塔果、全裸魔法、圣泥徽记保持既有译法。

额外补回一处被“堕天使”泛化的Alma姓名。两处彩色姓名先后顺序不同已核对：Alma回答Memoria，Pluton创造Zeukrees；现有中文语序没有混淆角色，不按标签位置交换姓名。

旧译名和先前用户决定保留于策略history、批次previous_translation及备份。人名使用英文版拼写；日文用于核对身份，不能把日版角色改名替换进英文版。Sp.不展开；原79条属性缩写保护继续生效。

## 验证与交接

55项Python测试、编辑器核心测试及隔离Edge浏览器测试通过。逐条检查12,204条当前目录的人名保留；64个规范批次及当前覆盖层的源哈希、控制代码、数字、出处和文本映射通过校验。模型稿仍为12,055条、普通待译及未答复均为0；7条原文、79条属性模板、63条程序指令继续保留。

新规则已加入批次准备与提交校验，防止遗漏英文姓名或重新引入登记过的旧中文姓名。未登记的新人物仍须按规则识别并加入登记册；自动检查不能证明全游戏不存在尚未识别的人名。

三语编辑器已刷新。浏览器中用户主动编辑过的草稿继续保留，必要时可在对应条目使用恢复内置稿查看新版。游戏及旧0.2.1玩家包未更新，未启动或操作游戏。
