# 0.3.6-fps-compat

2026-11-08。只调整安装器兼容性，全部202项汉化资源和13个输出BIN与0.3.5逐字节一致。

支持Steam英文版build 1527978的原版主程序，以及用户制作的60帧补丁1.0.0。帧率补丁仅将主程序偏移0x2FE1C处3字节从`0f be 08`改为`6a 3c 59`，不改资源包。汉化只改资源包，不写主程序。此前冲突来自汉化安装／还原／差分准备只接受原版EXE哈希，并非两种补丁修改了同一文件。

本版三个入口使用同一完整文件哈希校验，状态审计也能识别这版60帧主程序：

| 主程序 | SHA256 |
| --- | --- |
| 原版30帧 | d0e7cb34119313a61bef149517d29b3adb886c37456d21b2c2301a38338f1e5e |
| 用户60帧补丁1.0.0 | 001ade6dde612c93968009ac71a62070b1222e69bbe07f6201c0d1c942211548 |

任一安装顺序均可：先60帧再汉化，或先汉化再60帧。用本版安装器还原汉化时保留当前60帧主程序；用帧率工具还原30帧时保留汉化资源。两套备份分别保存在.mcowh-zh-backup与_fps_unlock，不互相覆盖。汉化安装包不包含帧率补丁，仍由用户自己的工具安装／卸载60帧。

未知EXE改动仍会被拒绝；资源包仍须与原版／本项目已安装状态的完整哈希相符。没有取消版本检查，也没有用文件大小或版本号代替文件校验。

离线验证见test-verification-0.3.6.json；独立汉化EXE的标准安装验证见release-verification.json。交叉测试使用用户的实际patch_core.py，只对work下的隔离副本应用两种补丁，覆盖两种安装顺序、单独卸载、重复安装、旧版还原和202资源／8字库审计，见fps-compat-verification.json。对实际游戏与存档不做写入、不启动游戏；帧率与游戏内表现仍由用户验收。

升级时请使用本版MCOWH_Chinese_Patch.exe及同目录patch.mcpatch，旧汉化安装器仍可能拒绝60帧主程序。若需重装汉化，用本版先“还原原版”，再“安装汉化”；两步都保留当前帧率补丁。已装0.3.5的译文与资源本身无需变更。
