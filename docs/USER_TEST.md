# 0.3.2-panel-only 用户验收

1. 退出游戏，完整解压本版ZIP。如果已装0.3.0/0.3.1，先运行安装器“还原原版”，然后安装本版；保留.mcowh-zh-backup和存档。
2. 通过Steam手动启动游戏。检查主菜单、设置、开局三行选择的字体和图片是否恢复到0.3.0的样式。
3. 打开人物面板，逐项核对下面19项，尤其MOV应为“移速”；检查字距、数字是否重叠及有无缺字。开局准备的属性面板也请检查。
4. HP、ST、EN、Lv、Exp、WT应保留0.3.0样式，上方HUD和其他内容应与0.3.0一致。
5. 如有问题，提供截图、所在界面和分辨率。开发方不会启动游戏或发送按键。
