# 0.3.5 用户手动验收

1. 退出游戏，完整解压MCOWH-zh-CN-0.3.5-trophy-fix.zip。运行新版安装器，先“还原原版”，再“安装汉化”。Steam语言保持English，保留.mcowh-zh-backup和存档。
2. 使用已有存档进入选职业界面：重点核对截图中海盗与风来人的通关标识，应与原英文版已有记录一致（提供的截图为海盗1枚、风来人3枚）。其他职业与不同难度记录也应正常。无需重新通关。
以下为可选历史回归项，用户已反馈0.3.4其他问题解决，无需为本轮重复验收。

3. 正常触发或回看序章、已解锁的结尾／后日谈。第一段应为“从前，有一个没有名字的世界”。检查翻页、背景切换、颜色、玩家名插入及末页；不要求为验收专门打通所有结局。
4. 在原先出现been killed by的开局对白中，检查死因是否中文。普通旧怪物死因会显示“死于……”，已是中文的死因应维持原样。未知怪物名可能保留英文。无需专门死亡，正常游玩遇到时提供完整句子截图即可。
5. 回归检查：使用次数和ST足够的技能，弹出菜单不得显示500000/400000，使用与快捷栏正常。普通物品的装备／卸下／拾取等选项也应起效。
6. 下列19项属性仍保持已确认译名，尤其MOV为“移速”。HUD中的HP/ST/EN/Lv/Exp/WT及人名保持既有形式。
