# 0.3.3 用户手动验收

1. 退出游戏，完整解压本版玩家ZIP，运行新版安装器，先“还原原版”，再安装0.3.3。保留安装备份和存档，Steam语言为English。
2. 通过Steam启动游戏。选中尚有剩余使用次数、ST充足的技能（例如尚未用完的觉醒），检查弹出选项仅显示“使用”“快捷栏”，后面不应出现500000、400000等编号。
3. 执行“使用”，确认技能实际发动、剩余次数/消耗/状态按该技能规则变化；执行“快捷栏”，确认能够绑定或解除快捷栏。已用完次数或消耗不足的技能不能用来判断该修复是否成功。
4. 选择普通装备或非贵重物品，检查装备、卸下、拾取、投掷和丢弃菜单的显示和实际效果；返回/取消按钮应进入正确分支。
5. 核对人物面板的19项属性依旧如下，尤其MOV为“移速”；主菜单、图片、字体和HUD应与0.3.2一致。
6. 如仍有数字露出或选项无效，提供补丁版本、所在界面、剩余次数/ST和截图。开发方不会替你启动游戏或发送按键。
