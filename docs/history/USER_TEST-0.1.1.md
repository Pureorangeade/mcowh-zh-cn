# 0.1.1 字体修正版：用户验收清单

由用户自行启动游戏、操作和截图。开发方仅检查文件、处理翻译、字体和补丁，不操作游戏界面。

## 本轮先做什么

2026-11-07 用户已完成 0.1.1 字体复验，提供设置菜单和声音设置两张截图。截图中的汉字粗细协调，未见明显缺字、乱码、旋转、重叠或裁切。这两个页面的可见中文显示通过；其他页面和交互行为仍需分别验证。

当前已安装 0.1.1，**无需再次安装或还原**。本轮继续下面的 B：新手教程开场；遇到木盾时再做 C，不必专门刷物品。无需通关，也无需统计整部游戏的汉化率。

若教程入口不好找，发当前菜单截图即可；不要为了验收覆盖现有进度。

### A. 启动和设置菜单（两个截图页面的可见中文已通过，留作回归步骤）

1. 自行通过 Steam 启动本游戏。
2. 标题中的 `Start / Extras / Options / Quit` 仍可能是英文，这是已知的未汉化内容。进入 `Options`。
3. 预期能看到以下中文菜单文字：

   ```text
   键盘设置
   手柄设置
   声音设置
   系统设置
   Twitter 设置
   显示设置
   恢复默认
   ```

4. 截取一张整个设置菜单的图。不要只截文字，以便判断窗口边界和文字位置。
5. 进入“声音设置”：预期有“音量设置 / 语音语言”，语音选项文字为“英语 / 日语”。如果可进入，再截一张图。
6. 如方便，进入“显示设置”：预期有“画面大小 / 显示模式”和“窗口 / 全屏”。只需查看；本轮不要求修改分辨率或恢复默认。

观察：同一行汉字是否粗细一致；是否有方框、空白、乱码、旋转、上下错位、明显大小不一致；是否被边框裁切或叠在一起；菜单选中和返回是否正常。已提供的两个页面无需重复截图；`Options / Sound Settings / BGM / SFX / Voice / MAX` 仍为已知未翻译内容。“显示设置”、其他分辨率及按钮操作未由这些截图证明通过。

**如果中文完全没有出现、出现错误窗口或游戏崩溃，先反馈 A，暂不继续 B/C。** 保留报错原文或截图。

### B. 新手教程开场（入口方便时做）

如果菜单中有新手教程入口，进入教程并查看开场前几段对话。预期依次包括：

```text
……喂……
……喂——……
……我说，喂！
真是的！你怎么了？
一直在这里发呆……
```

后续应出现自称“梅莫莉娅”的中文对话，以及“光就在我们身后”等提示。这次只翻译了开场 8 个脚本，后面的教程仍可能为英文。

请截一张包含多字中文对话和人物头像的完整画面。检查颜色、换行和方向图标；若画面直接显示 `\c[51]`、`\i[7500]` 这样的控制代码，也请反馈。

如有进行中的冒险、没有找到教程入口，或开始教程会影响你要保留的进度，先跳过 B，反馈当前菜单即可；无需删除或覆盖存档。

### C. 木盾名称和说明（遇到时做，不必专门刷）

遇到原文名为 `Wooden Shield` 的物品时，打开其详细说明。预期名称为“木盾”，描述包括：

```text
木制盾牌。
格挡几率 +80%。
格挡时，防御 +4，伤害减免 +20%。
```

请截一张含名称和完整说明的图。检查百分号、数字、颜色、换行和文字裁切。没有遇到木盾就标记“未测试”。

```text
B 教程对话：正常 / 异常 / 未测试

```

请区分“预期范围内的文字没有被替换”与“范围外仍是英文”。本轮不要求收集所有未翻译文本。

## 验收之后

开发方据截图修复字形、布局或资源加载问题；A/B/C 分别记录通过、失败或未测试。在实际显示验证完成前，继续保留“技术演示、待验收”标记。后续再扩大译文和测试范围。
