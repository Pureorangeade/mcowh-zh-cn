## 字体与资源

- 已知 8 套字库均覆盖本次 2,384 个非 ASCII 字符；新增字符通过扩展 Phyre 字形数组写入，保留所有原码点、ASCII 记录和原始字图像素。
- 同时更新数组数量、字节长度、四字节对齐、对象大小和字形数组修复记录；未修改时 8 个原字体的元数据可逐字节重建。
- 新字符使用已验证的字重：regular 500、demibold 600、Skip 700。用户在 0.2.0 的标题、角色准备、载入提示和人物栏截图中已确认大量中文可见；这不是全字库或完整流程验收。
- 187 张专用文字图包含主菜单、职业名、背包页签、设置标题、距离和部分结算提示。原图尺寸、透明通道、元数据和文件字节长度保留，译文墨迹限制在原文字边界内，离线缩略图已检查。
- 201 个资源重建并重新读取校验；共生成 13 个修改文件，约 1.55 GB。分发只携带差分，安装时从玩家原文件重建。

## 翻译来源与保护

初稿在本机 GPU 上运行 [Helsinki-NLP/opus-mt-en-zh](https://huggingface.co/Helsinki-NLP/opus-mt-en-zh) 生成，版本固定为 `408d9bc410a388e1d9aef112a2daba955b945255`。不向外部翻译服务发送游戏文本。模型和开发运行环境不放入玩家包。

控制代码、变量、数字字面量、原换行、嵌套图标参数、配置节名、程序指令和资源路径不交给翻译模型。脚本用原文哈希和精确位置定位，重复对话不会误替换。数据库只修改允许的显示字段，事件只修改对话正文和选项参数。

机器输出经过控制代码、私用字符和重复输出检查；发现的问题保留原文或人工修正，并标记待校对。这些检查不证明译文含义、文风或术语已经正确。

开发方不启动或操作游戏。本轮不覆盖实际游戏资源；升级和游戏内验收由用户完成。

HUD 中很小的 LV 字样、职业代码 SW/KN/AR 等保留原样，避免缩写被误译或小尺寸汉字无法辨认。

## 0.2.1 修订与编辑方式

标题主菜单统一限制可见字形高度为 68 个原生像素，三个开始子菜单限制为 48 像素，保留原画布、位置与资源格式。人物状态、能力、详情下的 STR/VIT/AGI/INT/WIL/CHR、LOK/CLM/SWM、ATK/FOR/ARM/RED/ACC/MOV/EVA/COM/CRI/ID 等恢复原版缩写，具体条目以源模板为准，栏位标题仍中文。

新增独立 HTML 中英对照编辑器，覆盖以上主文本、系统文本和图片文字共 12,204 条。人工修订按 ID 和原文哈希单独导入构建，不改写机翻底稿，详见 EDITING.md。该功能便于逐条校对，不代表现有机翻已经润色完成。
